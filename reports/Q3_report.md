# 问题三：通信约束下的运输与中继联合调度报告

## 1. 当前阶段与基线

本阶段只处理问题三。题面要求在问题二运输架次基础上保证连续通信，并在直连不可用时搜索空中中继。当前实际基线取工作区 results/Q2_运输架次.csv：24 架次、完工 7730.5 s、总运输能耗 78.265387 kWh；该文件与 reports/Q2_ANALYSIS_MODELING.md 一致。plan.md 中另有29架次/8143.7 s的历史版本，属于未同步版本，本阶段不将其混入计算。

## 2. 实际读取的文件、版本和依据

- 题面：scratch/problem_text_latex.md，问题三、附录2、附录3。
- 运输基线：results/Q2_运输架次.csv。
- 节点：数模题目/D题/数据/无人机应急物资运输基础数据/调度中心与服务区.xlsx，15个服务区和O01。
- 通信参数：通信链路参数.xlsx，f=2400 MHz，Lsys=3 dB，Lobs=10 dB，Psens=-98 dBm，M=8 dB；G01 Pt/G/hG=27/12/20，运输机20/3，中继接入20/6，中继回传19/8。
- 地形：镇龙乡及周边30米DEM.tif。脚本按GeoTIFF分块读取、双线性地面高程插值。
- 中继参数：中继无人机数据.xlsx，R型可用能量3.2 kWh、SOC下限20%、最大悬停离地300 m、悬停功率1.05 kW、通信附加功率0.05 kW。

## 3. 模型、判定和代码映射

对任意三维端点，先按20 m采样步长检查LOS；再按题面公式计算 L_FSPL=32.45+20log10(f)+20log10(D_km)，遮挡时加Lobs；双向门限取两方向允许损耗最小值。运输机在每个采样时刻的状态为：直连可用则“直连”；直连不可用且运输机—中继、中继—G01同时可用则“中继”；否则“中断”。

脚本：code/Q3/q3_solver.py。候选中继点为O01、15个服务区和两两服务区中点，悬停离地高度为50/150/250 m，均满足300 m上限；共363个候选。对每个架次的每条航段往返航迹按21个节点采样（多点架次为每段21点），搜索可覆盖全程的候选中继点并以接入+回传距离最小为候选目标。

## 4. 真实结果及来源字段

结果文件为 results/Q3/Q3_通信保障.csv、results/Q3/Q3_中继任务.csv、results/Q3/Q3_summary.json。

- 架次：24；通信采样点：1344。
- 直连架次：24；需要中继架次：0；通信中断架次：0。
- 直连损耗范围：79.85–118.23 dB；最小双向门限裕度：3.77 dB。
- 因当前基线全程直连可用，中继飞行/悬停/通信服务能耗为0，中继无人机和能源组件使用架次为0。
- Q3_通信保障.csv字段 直连损耗_dB、直连阈值_dB、直连LOS、通信状态给出每个采样点证据；Q3_中继任务.csv给出每架次服务时间与通信汇总。

## 5. 约束校验与审计结论

1. 货箱、路线和运输资源继承Q2 CSV；本阶段未改写Q2。
2. DEM范围内的候选悬停点、离地高度50/150/250 m均不超过300 m。
3. 连续通信：1344/1344采样点为直连，0中断。
4. 通信参数全部来自附件；没有用未注明覆盖半径替代链路预算。
5. 中继资源未被启用，因此中继能量、服务时段冲突和中继返回约束均为零需求；候选中继方案作为不采用方案保留。
6. 该结果是当前24架次基线下的可行通信判定，不宣称联合全局最优；若切换到plan.md的29架次历史基线，必须重新运行Q3。

## 6. 失败/未采用方案与局限

- 未采用中继方案：直连已覆盖全部采样点，额外中继会增加能耗和资源占用，且没有通信收益。
- 未发现通信中断方案：当前数据和基线下无中断；因此无法从真实数据生成“中继成功”的样例。
- 采样判定是离散近似，步长20 m；中继候选点采用节点和中点网格，不等同于连续空间全局优化。
- 结果依赖Q2版本；版本冲突已记录，不能把24架次结果表述为29架次版本的结果。
