# 阶段一：三机并行赛马比对与打分基准说明

本项目用于在阶段一截止时，归档并横向比对电脑 A、B、C 跑出的 Q1+Q2 方案，以便根据统一基准进行量化打分并锁定唯一胜出方案。

---

## 一、 子文件夹目录划分

- `computer_A/`：存放电脑 A 提交的 Q1+Q2 分析文档、结果表与复现代码
- `computer_B/`：存放电脑 B 提交的 Q1+Q2 分析文档、结果表与复现代码
- `computer_C/`：存放电脑 C 提交的 Q1+Q2 分析文档、结果表与复现代码
- `computer_D/`：存放电脑 D（B 与 C 融合整合版）提交的分析文档与标准结果表

---

## 二、 每位队员 / 电脑必须提供的文件清单

请各电脑在各自目录下放置以下 **4 个标准化文件**（格式可为 CSV 或 Excel）：

### 1. `Q1_单点组批.csv`（或 `.xlsx`）
- **必须包含字段**：
  - `架次编号`（如 T01, T02...）
  - `执行机型`（A型 / B型 / C型）
  - `目标服务区`（S001 ~ S015，不可跨服务区）
  - `所装货箱列表`（如 `[B01, B02, B05]`）
  - `装载总质量_kg`（需 $\le$ 安全载荷及额定载重）
  - `装载总体积_m3`（需 $\le$ 额定容积）
  - `往返总能耗_kWh`
  - `往返总时间_s`
  - `返航剩余SOC_%`（需 $\ge 20\%$）

### 2. `Q2_运输架次.csv`（或 `.xlsx`）
- **必须包含字段**：
  - `架次编号`（如 T001, T002...）
  - `执行机型`（A / B / C）
  - `执行实体机编号`（严格限定 U01~U08：A型 U01~U04，B型 U05~U06，C型 U07~U08）
  - `指派电池编号`（严格限定：A型 Bat_A_01~06，B型 Bat_B_01~04，C型 Bat_C_01~04）
  - `起飞时刻_s`
  - `返回时刻_s`
  - `航线序列`（如 `O01 -> S002 -> S004 -> O01`）
  - `起飞总质量_kg`
  - `总能耗_kWh`
  - `返航剩余SOC_%`（需 $\ge 20\%$）

### 3. `Q2_逐箱交付.csv`（或 `.xlsx`）
- **必须包含字段**：
  - `货箱ID`（80个货箱，B01 ~ B80，不可漏、不可重）
  - `所属服务区`（S001 ~ S015）
  - `承运架次编号`
  - `承运机型`
  - `物资类型`（医疗 / 首批 / 普通）
  - `实际送达时刻_s`
  - `截止时限_s`
  - `期望时限_s`
  - `是否违约`（**医疗和首批必须 100% 为“否”，违约即 0 分**）
  - `提前送达时间_s`（期望时限 - 实际送达时刻）

### 4. `方案指标与自述简报.md`（或 `.txt`）
- 简述算法原理与全局随机种子（Random Seed）
- 核心指标速报：
  - Q1 总架次、Q1 总能耗 (kWh)、Q1 累计时间 (s)
  - Q2 Makespan 全任务完工返回时刻 (s 或小时)
  - Q2 首批/医疗物资违约箱数（必须为 0）
  - Q2 平均提前送达时间 (s)
  - Q2 总架次、Q2 总能耗 (kWh)
- **Q3 通信预警**：是否有同一时段 $\ge 2$ 架无人机在深山地形遮挡盲区飞行？
- **Q4 分区预警**：多点串联回路具体绑定了哪几个服务区？
- **复现脚本**：附带 `problem1.py` 和 `problem2.py`
