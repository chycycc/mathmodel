# 山区洪涝灾害下无人机运输与通信协同优化
## 0. 本阶段范围与结论
本阶段只完成问题一和问题二。问题一给出三类运输无人机在15个服务区的连续最大安全载荷及货箱组批；问题二给出满足逐箱时限、实体无人机、共享电池和充电周转约束的异构运输调度可行解。问题二的当前解使用单点往返作为允许路线集合中的可行子集，先保证时限和资源核验完整；跨服务区多点串联可在下一阶段加入同一模型继续压缩架次数。

数据核对：1个调度中心、15个服务区、80个不可拆货箱、8架运输无人机（A×4、B×2、C×2），共享电池 A/B/C 分别为6/4/4组。

## 1. 总体建模框架
题面 → 节点和货箱数据清洗 → DEM沿直线航段采样 → 问题一单点能量容量与组批 → 问题二时限优先调度 → 逐箱时刻、SOC和资源校验。问题三的通信约束不进入本阶段。

## 2. 数据与计算口径
- 调度中心与服务区表提供节点经纬度、地面海拔和人口；物资表提供80个货箱的质量、体积、首批标记、截止时间和期望送达时间。
- 运输机型表提供空载质量、最大载荷、装载体积、巡航速度、空/满载标准航程、电池可用能量、返航电量下限和作业时间参数。
- DEM为30 m栅格，使用两端节点连线上的栅格最高地面高程加50 m作为计划巡航海拔。经纬度距离使用局部球面近似，航段不沿道路。
- 有效航程采用题面公式 Lg(q)=Lg0-(Lg0-LgF)(q/Qg)^(3/2)。水平能耗按 Euse*d/Lg(q)，爬升附加能耗按 (mg+q)g h+/(3.6×10^6 ηg) kWh，下降附加能耗按附件给定的0处理。
- 架次能耗满足 ETp≤(1-ρg)Euseg，本题三类机型均取返航电量下限20%。

## 3. 假设敏感性预检
### 模糊表述及解释
1. “返航安全余量”可解释为整架次能耗上限，或解释为每个航段结束后都必须保留余量。题面给出 ETp≤(1-ρg)Euseg，因此采用整架次能耗上限；逐段检查作为额外安全校验。
2. “最大安全载荷”可按连续质量求解，也可只在货箱质量和体积组合中取离散值。报告先给连续能量上限，再用不可拆货箱的整数组批给出离散执行方案。
3. 问题二允许多点访问，但直接往返是其特殊可行路线。本阶段以直接路线构造可核验基线，不把该基线宣称为包含多点串联的全局最优。

### 快速验算与递进性检查
DEM抽样得到调度中心高程约128.73 m，S010约321.58 m，与节点表给出的地面海拔量级一致；15个服务区的直线距离约2.82–8.11 km。连续载荷随返航余量增大而单调下降，说明余量约束方向正确。

### 最终采用的解释
使用整架次能耗上限、连续最大安全载荷加整数货箱组批、问题二采用时限优先的异构资源调度。

## 4. 问题一模型
### 4.1 变量与约束
对机型g、服务区i，令 qgi 为连续载荷。航段时间为 t_gij=h+ij/v↑g+dij/vcg+h−ij/v↓g，航段能耗为 Egij(q)=Ehor_gij(q)+Eup_gij(q)。直接往返安全载荷满足：

qgi≤Qg，且 E_g,Oi(qgi)+E_g,iO(0)≤(1-ρg)Euseg。

货箱组批用整数变量 x_ikt 表示服务区i的第k架次装载物资类型t的箱数，满足每箱一次：Σk x_ikt=n_it；质量和体积分别满足 Σt mt x_ikt≤Qg、Σt vt x_ikt≤Vg，并对每个架次再检查能耗约束。

### 4.2 目标与算法
采用字典序目标 (N,E,T)：先最小化总往返架次N，再最小化总运输能耗E，最后最小化累计作业时间T。对每个服务区和机型枚举四类货箱数量模式，剔除质量、体积和能耗不可行模式，再用四维整数动态规划覆盖需求向量。

## 5. 问题二模型
### 5.1 决策变量
对架次r决定机型gr、实体无人机ur、共享电池br、服务区访问序列、货箱集合和开始时刻sr。本阶段的执行解全部采用 O01→Si→O01，因此路线约束自动满足；多点路线只需将航段集合扩展为连续服务区序列。

### 5.2 目标与约束
采用“时限硬约束 + 字典序”目标：首先保证首批箱和全部货箱不晚于各自截止/期望时间，然后最小化架次数、完成时间和总能耗。约束包括货箱唯一配送、质量/体积/能耗、首批截止时间、实体无人机不重叠、同型共享电池不重叠、充电周转和SOC不低于20%。

共享电池充电时间使用题面两阶段模型：SOC低于90%时按 Tfull[0.65(0.90-s)/0.90+0.35]，SOC达到90%后按 Tfull·0.35(1-s)/0.10。

### 5.3 求解方法
先把每个服务区拆成“首批/最早期望箱”和普通箱，分别枚举A/B/C型可行模式；以截止时间、优先系数为排序键做列表调度，在每一步选择最早可用实体无人机和共享电池。随后用随机重启搜索机型组合，评价顺序为：逾期箱数、总逾期秒数、架次数、完成时间、能耗。

## 6. 结果校验与局限
- 逐箱覆盖：80个货箱在输出清单中恰好出现一次。
- 时限：首批箱按首批截止时间检查，普通箱按期望送达时间检查，逾期箱数为0。
- 载荷和体积：每个架次均由模式枚举过滤；能耗：每个架次均满足 (1-ρ)Euse。
- 资源：按实体无人机和电池可用时刻推进，充电期间不允许同一电池重复占用。
- 局限：问题二当前解未使用跨服务区多点串联，因此是可复核的时限优先可行解而非含多点路线的全局最优；下一步可用列生成或ALNS扩展候选路线并以当前解作上界。
